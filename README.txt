THE LUMSDEN COLLECTION — WEBSITE PACKAGE

Included pages:
- index.html: homepage
- Gallery.html: complete gallery with category filters and artwork viewer
- Dark.html: dark-ground artwork collection, using a dark website theme
- Japanese.html: Japanese & Manga collection, using the light website theme

Assets:
- 14 new artwork photographs in images/new-works/
- 4 cleaned drawings in images/japanese-manga/
- gallery.js and style.css

The package contains 18 artwork images. Every image is included locally.

Navigation intentionally includes only pages supplied in this package. Exhibition and Contact pages were not supplied, so there are no links to missing pages. Contact enquiry copy remains on the homepage; add the artist's contact details when available.

The original 13 artwork images from the live website are not included in this package. Preserve/copy those original assets separately if they are to remain in the live site.

To publish, upload the contents of this ZIP into the existing GitHub Pages repository. Back up the repository or create a feature branch first.
